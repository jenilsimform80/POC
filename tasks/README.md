# Tasks

- [backlog.md](backlog.md) — all tasks by phase.
- [phase-status.md](phase-status.md) — completed/pending phases, decisions, blockers, next approved step.

## Task fields
ID (`POC-<AREA>-NNN`; areas DOC, BE, DB, AUTH, API, LOCK, RPT, FE, QA, OPS) · Title · Description · Phase · Priority (P0 highest–P2) · Dependencies · Acceptance criteria · Status (Todo / In Progress / Blocked / Done) · Tests · Docs/files.

## Rules
- One task In Progress at a time; only for the approved phase.
- Done only when acceptance criteria and listed tests are verified by actually running them.
- Update the status here and in `phase-status.md` when work is genuinely complete.
- Phase 0 tasks are detailed; later phases start as outlines and are refined (split into smaller tasks) when the phase is proposed for approval.
